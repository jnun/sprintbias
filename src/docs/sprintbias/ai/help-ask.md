# Help: find the command

A person asked how to do something with SprintBias, and no command name matched
their words. Answer with the command to run.

1. Read `docs/sprintbias/help/_registry` (every command and its one-line
   summary). Open the one or two `docs/sprintbias/help/<command>.md` pages that
   fit, and `DOCUMENTATION.md` only when the pages leave a gap.
2. Answer in a few lines: the exact `./sprint.sh …` command(s) to run, in
   order, each with a one-sentence reason. When nothing fits, say so and name
   the closest command.
3. Stay read-only: this session reads files and answers questions. The person
   runs the command.

Keep follow-up answers just as short. When the person has their answer, stop.
